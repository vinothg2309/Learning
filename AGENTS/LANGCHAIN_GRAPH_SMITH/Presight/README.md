# Presight AI Security Interview Preparation

This directory contains comprehensive study materials for the AI Security role interview at Presight.

Based on the job description, key areas to focus on include:
- Core agentic AI platform (AI SOC, AI Pen Testing, AI Secure Code Review)
- Tool integrations (SIEM, Tenable, ExtraHop, GitLab, Fortify, sandboxes, MITRE frameworks)
- AI security controls and guardrails (PLOT4AI, OWASP LLM Top 10, MITRE ATLAS, NIST AI RMF)

## Directory Structure
- `agentic_ai_platform.md` - Deep dive on AI agentic systems for security
- `tool_integrations.md` - Detailed guide on integrating with security tools
- `ai_security_controls.md` - Implementation of guardrails and safety controls
- `frameworks_details.md` - Explanation of PLOT4AI, OWASP, MITRE, NIST frameworks
- `practical_lab_ideas.md` - Hands-on exercises to build and practice
- `interview_questions_prep.md` - Potential interview questions and preparation tips
